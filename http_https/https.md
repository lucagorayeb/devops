# HTTPS

- O HTTPS é a versão segura do HTTP.

- É encriptado para garantir a segurança da transferência de dados.

- O protocolo usado para a criptografia são o Transport Layer Security (TLS).
  Esse protocolo faz a segurança por meio da infraestrutura de chave pública assimétrica.

- A infraestrutura de chave pública assimétrica utiliza um par de chaves, uma pública e 
  uma privada. A chave pública, como o nome diz, é de conhecimento público, enquanto a
  chave privada pertence a cada servidor. Uma só pode ser autenticada com a outra.

- O protocolo HTTPS usa por padrão a porta 443.
