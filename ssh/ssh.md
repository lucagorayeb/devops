# SSH

- É um protocolo de segurança para o login remote de um computador a outro.

- O SSH é usado para:
    - Prover acesso seguro para usuários e processos automáticos.
    - Transferência de arquivos interativa e automática.
    - Gerenciar infraestrutura de rede e outras coisas críticas dos componentes
      do sistema.
    - Passar comandos remotamente.

- A conexão do SSH é estabelecia pelo o cliente ssh ao servidor ssh. A autenticação é 
  com base em chaves assimétricas. Depois que a fase de autenticação é concluída as
  informações trocadas são todas protegidas para chave simétrica e algoritmos de hash
  para garantir a privacidade e a integridade da comunicação.

- A porta padrão do SSH é a 22.
