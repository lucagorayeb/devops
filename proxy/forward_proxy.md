# Foward Proxy

- É um sistema ou um roteador que promove uma porta entre os usuários 
  e a internet.

- Ajuda a impedir que atacantes entrem em redes privadas.

- É um servidor, mas é referido como intermediário pois fica entre os
  usuários finais e as páginas web.

- Quando um computador se conecta a internet ele adquire um endereço IP.
  Que é similar ao endereço da rua, que informa ao dado enviado onde ir 
  e marca a o dado de saída com um endereço de retorno para outros
  dispositivos autenticarem. 

- O servidor proxy é essencialmente um computador na internet com IP 
  próprio.

## O que é um servidor proxy?

- É uma porta para a internet. O servidor proxy age como um homen do meio
  (middleman) entre o dispositivo e a web.

## Servidores Proxy e Segurança 

- Podem servir de filtros ou de firewalls para proteger de ameaças da internet.

- Os proxy pode ser usado para:

    1 - Melhorar a Segurança
    2 - Deixar os empregados seguros caso alguém tente bisbilhota-los.
    3 - Fazer o balanceamento de rede para impedir falhas.
    4 - Controlar o acesso dos usuários.
    5 - Salvar banda larga fazendo cache dos files ou compimindo 
        tranfégo.

# Como o Proxy funciona

- Existem dois tipos de proxy, o hardware e o software.

    Hardware -> O hardware é uma conexão que fique entre o cliente e a internet
                onde ele pode pegar, enviar e encaminhar data para a web.

    Software -> Proxies são geralmente hospedados por um provedor ou ficam em uma 
                nuvem. Faz o download de uma aplicação que permite interagir com o 
                mesmo.

## Como o proxy protege a privacidade computacional e os dados

- O proxy faz a função de um filtro e de um firewall. Os usuários finais ou o 
  administrador de rede escolhe o proxy para proteger dados e privacidade.  

- Examinam os dados entrando e saindo do computador ou da rede.
